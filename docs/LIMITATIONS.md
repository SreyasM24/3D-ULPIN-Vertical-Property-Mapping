# Prototype Scope, Boundaries & Engineering Limitations

## 1. Statutory Prototype Disclaimer
> [!IMPORTANT]
> This software is an **engineering research prototype** developed for the **Smart India Hackathon (SIH) 26011**. It is not currently certified or officially deployed as India's National Cadastral Registry. All 3D ULPINs, property boundaries, and volume calculations generated by this system are advisory decision-support outputs intended to assist state survey departments and the Department of Land Resources (DoLR), Government of India.

---

## 2. Technical Scope & Current Boundaries

### 2.1 Architectural Geometry
- **Supported Topologies**:
  - Prismatic extruded polygons with horizontal vertical strata.
  - Multi-floor residential and commercial complexes with basement levels ($B01\dots$), ground floor ($G00$), and upper floors ($L01\dots$).
  - Rectangular and corridor-based unit horizontal subdivisions.
- **Current Geometric Limitations**:
  - Complex non-vertical cantilevers, free-form organic roofs (e.g. hyperbolic paraboloids), and sloping floors are approximated via bounding planar slices.
  - Full IFC / BIM wall-and-duct internal room segmentation is beyond the current scope; unit boundaries are partitioned deterministically from building boundary polygons.

### 2.2 Point Cloud & Elevation Processing
- **Supported Sensors**:
  - ASPRS LAS 1.2, 1.3, and 1.4 point clouds (uncompressed `.las`).
  - GeoTIFF single-band digital elevation models (DEM, DSM, DTM).
- **Scale Boundaries**:
  - The in-process Python pipeline comfortably processes point clouds up to $500,000$ points within $< 2\text{s}$.
  - Massive multi-gigabyte or nationwide continuous aerial LiDAR surveys require distributed spatial partitioning (e.g., Apache Sedona, PDAL tile pipeline, or AWS Lambda spatial workers) which is documented in the architectural roadmap.

### 2.3 Machine Learning & Advisory Safeguards
- **Inference Scope**:
  - SpaceNet UNet footprint extraction is calibrated on aerial and satellite imagery of $0.3\text{m} - 0.5\text{m}$ ground sample distance (GSD). Lower resolution imagery ($> 2.0\text{m}$) yields degraded IoU.
  - The Height Regressor MLP provides statistical estimates based on urban morphological indicators and should never replace ground surveyor measurements.
- **Evidence Conflict Governance**:
  - The system will **never** automatically resolve legal boundary conflicts. When discrepancies exceed $2\sigma$, the system safely freezes automatic registration and flags the parcel for human cadastral officer review.

## 3. Production Roadmap to National Scale
1. **BIM / IFC Ingestion**: Integration with `IfcOpenShell` for direct extraction of as-built apartment units from architect-submitted IFC4 files.
2. **Distributed Spatial Tiling**: Cloud-native point cloud streaming via COPC (Cloud Optimized Point Clouds) and EPT (Entwine Point Tile).
3. **Hardware Security Module (HSM) Integration**: Cryptographic digital signing of 3D ULPIN registry deeds using Aadhaar eSign or standard X.509 officer certificates.
4. **National Land Records Modernization Programme (NLRMP) Integration**: Direct bidirectional connector with state Bhulekh / BhuNaksha land registries.
