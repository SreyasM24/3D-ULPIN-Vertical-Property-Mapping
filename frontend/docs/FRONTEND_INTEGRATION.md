# SIH 26011: 3D ULPIN & Vertical Property Mapping System
## Frontend Integration Specification & API Contract

### Overview
This frontend connects directly to the FastAPI cadastral engine running on `NEXT_PUBLIC_API_BASE_URL` or `VITE_API_BASE_URL` (default: `http://localhost:8000/api/v1`).

### Unified Response Envelope
Every backend endpoint adheres to the standardized envelope:
```json
{
  "success": true,
  "data": { ... },
  "error": null,
  "request_id": "req-94f8a-cadastral"
}
```

### Core API Endpoints

#### 1. System Health & Readiness
- `GET /health` -> `ApiResponse<SystemHealth>`
- `GET /capabilities` -> `ApiResponse<SystemCapabilities>`

#### 2. Survey Processing Jobs
- `POST /jobs` -> Initiate asynchronous cadastral reconstruction job
  Request Body: `CreateSurveyJobRequest`
  Response: `ApiResponse<ProcessingJob>`
- `GET /jobs/{job_id}` -> Poll status of processing job
  Response: `ApiResponse<ProcessingJob>`
- `GET /jobs` -> List recent processing jobs
- `DELETE /jobs/{job_id}` -> Cancel running job

#### 3. Parcels & Cadastral Boundaries
- `GET /parcels` -> List processed land parcels
- `GET /parcels/{parcel_id}` -> Fetch parcel boundaries, survey details, and ground attributes

#### 4. 3D Cadastral Digital Twin
- `GET /digital-twin/{parcel_id}` -> Full 3D Digital Twin structure (Parcel, Buildings, Floors, Units, Underground Volumes, Elevated Volumes, Shared Spaces)
- `GET /digital-twin/{parcel_id}/units/{unit_id}` -> Specific 3D vertical unit attributes, 3D ULPIN, and vertical bounds
- `GET /digital-twin/{parcel_id}/export` -> Export CityJSON / GeoJSON / OBJ payload

#### 5. Deterministic Validation Engine
- `GET /validation/{parcel_id}` -> Technical quality report, clash findings, and 102 deterministic rules evaluation breakdown
- `POST /validation/{parcel_id}/run` -> Re-run validation pipeline

#### 6. ML Review Signals & Anomalies
- `GET /ml/anomalies/{parcel_id}` -> Advisory spatial signals, encroachment indicators, and height discrepancy alerts
- `GET /provenance/{target_id}` -> Lineage, survey sensor method, ML model version, and uncertainty bounds

#### 7. Demo Pipeline
- `POST /demo/generate` or `GET /demo/digital-twin` -> Seed and load reference cadastral dataset (as generated by `scripts/generate_demo_dataset.py`)
